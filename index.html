Projects & Portfolio

  • 📊

    Customer Churn Analytics

    Data Analyst | ML Specialist

    Customer churn prediction project (solo, Jan to May 2026).

    • Problem: Predict which of 7,043 telecom customers will churn (26.5% churn rate) so retention teams can prioritize outreach.
    • Approach: SQLite + SQL EDA, 33 features, leakage-safe pipeline (split before feature engineering, train-only imputation and scaling, 5-fold CV inside tuning), tuned RF and XGBoost, isotonic calibration; 7 pytest tests.
    • Result: ROC-AUC 0.845; calibration cut RF Brier score from 0.159 to 0.135 at 80.5% accuracy vs a 73.5% baseline; highest-risk tier churned at 72.9% vs 9.8% for the lowest.

    News Sentiment Classifier

    ML Engineer | Backend Developer

    Financial headline sentiment classifier (solo, Apr to May 2025, refactored Apr 2026).

    • Problem: Gauge sentiment of current financial headlines without paying for an LLM API.
    • Approach: Scrapes multiple news sites (requests + BeautifulSoup, Selenium fallback when a fetch fails) and classifies each headline with a local Llama 3.2 model through Ollama, constrained to one positive/negative/neutral label at temperature 0 with a validation step; 4-worker thread pool, OOP design, pytest tests, Docker Compose packaging.
    • Result: In one containerized run, all 15 scraped headlines received a valid label.
